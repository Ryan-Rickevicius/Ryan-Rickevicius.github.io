# Portfolio Brief

## Audience

Recruiters and hiring managers for sports analytics, data analytics, and business analytics internships, with a focus on Summer 2027.

## Pages

Home, selected Work, Analytics Journal, About, and Contact.

## Design

A restrained editorial portfolio with navy text, teal accents, warm off-white backgrounds, readable type, and real analytical figures. Use varied compositions and plain text rows rather than repeated bordered cards. Present Ryan's actual experience directly.

Design references reviewed include Julia Silge's journal, Visual Cinnamon's project visuals, Yan Holtz's analytical project formats, and JJ Svenson's baseball report presentation.

## Content

Lead with the Quantifying the Tunnel research, followed by shareable first-pitch analysis and TrackMan scouting examples. Use the supplied resume for education, experience, tools, and interests. Add project evidence when it is available and appropriate to share.

## Editing and publication

Routine authoring should use a browser editor with fields for titles, summaries, topics, dates, article content, charts, and downloads. Support written analysis, PDFs, interactive charts, and supported dashboard embeds. Markdown remains the underlying portable format.

The website uses Hugo, a Pages CMS editor configuration, GitHub Actions, and free GitHub Pages hosting. Scheduled checks should publish due posts approximately every 15 minutes after successful builds. Exact-minute publication is not guaranteed.

## Implementation

The repository contains the complete static website, shared article templates, content editor configuration, draft preview workflow, and scheduled GitHub Pages publishing workflow. See README.md and CONTENT-GUIDE.md for setup and routine authoring. Pages CMS requires a one-time repository-owner connection before browser editing can be used.
